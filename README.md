# Ninjas vs Zombies

**Top-down survival browser game** — play as a ninja surviving endless waves of zombies in a classic ninja village.

Open `index.html` in any modern browser to play (assets load from `assets/` folder).

## Concept

You are a lone ninja in a ruined Japanese village at dusk. Zombies swarm from all directions. Survive using authentic ninja weapons. Push the score higher each run.

Fits Rokumon Games: original, short-session, distinctive style, browser-native, worth discovering.

## Weapons
Switch with number keys 1-4:
1. **Shuriken** — Fast ranged throwing stars
2. **Katana** — Powerful melee slash
3. **Grenade** — Area-of-effect bomb
4. **Kusarigama** — Chain sickle with reach

**Other ideas for future:** Kunai, Smoke Bomb, Caltrops, Nunchaku, Blowgun, Tetsubishi.

## New in this update
- **Dash** (Shift) — costs stamina, short cooldown, blue trail
- **Camera follow** — world is larger (1200x900), camera smoothly tracks the ninja
- **Sound effects** — Web Audio tones for attacks, hits, dash, power-ups, explosions

## Art Assets
- Village background (dusk ninja village with cherry blossoms)
- Ninja character sprite
- Zombie sprite
- Weapon icons (shuriken, katana, grenade, kusarigama)

Place them in `assets/` folder.

## Controls
- **WASD / Arrows** — Move
- **Shift** — Dash (uses stamina)
- **Mouse** — Aim
- **Left Click** — Attack with current weapon
- **1-4** — Switch weapons

## Running the Game

1. Clone the repo
2. Ensure assets are in `assets/`
3. Open `index.html` in a browser
